UFK LIVE SUPPORT + ADMIN UPGRADE

1. Open Supabase > SQL Editor.
2. Paste and run the entire SUPABASE-SETUP.sql file.
   It is designed to upgrade the database you already have.
3. Upload every website file from this folder into your GitHub repository.
4. In GitHub Desktop, commit and push the changes.
5. Wait for GitHub Pages to redeploy, then hard-refresh the website (Ctrl+F5).

NEW FEATURES
- Private live chat between each signed-in client and UFK admins.
- Admin support inbox with every client conversation.
- Manual purchase override for PayPal, Cash App, bank transfer, Discord payments, gifts, or other methods.
- Manual purchases are stored in the customer's shared account.
- Admin can approve/publish purchases to a public completed-order log.
- Public log displays “Admin approved this purchase” without exposing customer emails.
- Better admin controls for statuses, account revocation, deliveries, payment method, and manual orders.

IMPORTANT
- Run the SQL before testing the new website features.
- Keep your current admin account; the upgrade does not remove it.
- Do not upload a ZIP file into the repo. Extract it and copy the files/folders themselves.

POPUP CHAT + REMEMBER ME UPDATE
- Customer support now appears as a floating popup in the bottom-right after login.
- Admin replies remain inside the Admin Dashboard support inbox.
- Supabase sessions are stored in localStorage and automatically refreshed, so users and admins remain signed in across page reloads and browser restarts until they press Log Out.

LATEST UPDATE: OTHER PAYMENT APPROVAL + POPUP CHAT
- The live-support launcher is always visible in the bottom-left.
- Guests are prompted to log in; clients open chat; admins open the support inbox.
- Checkout now includes "Paid another way?" and a required Yes confirmation.
- Requests enter "Waiting for admin approval" and are sent to the admin portal/chat.
- Admins can click "Approve this purchase". Approval is saved to the client account,
  sent back through chat, and published in the public approval log with a direct link.
- The existing SUPABASE-SETUP.sql already contains the required tables and policies.
